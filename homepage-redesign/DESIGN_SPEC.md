# 盐城工学院教学成果申报网站 — 首页改版设计规范

> 版本：v1.0 | 日期：2026-06-21  
> 适用范围：首页及后续各栏目页面  
> 技术约束：第三方 CMS 平台（Freemarker 模板引擎），外部样式通过 `<link>` 追加引入

---

## 一、设计目标

| 目标 | 说明 |
|------|------|
| 第一印象突出 | 宣传视频作为核心内容优先呈现，比例协调，加载后自动吸引视线 |
| 数据可信度 | 以数据看板形式直观呈现成果体量，建立权威感 |
| 信息时效性 | 最新动态模块实时展示，增强平台活跃度 |
| 视觉升级 | 在 CMS 限制内，通过现代卡片布局、微动效、色彩层次提升整体品质 |

## 六、组件规范

### 6.1 模块标题组件

```
[左侧 4px 色块] [标题文字] [右侧装饰线延伸至右边]
                                              [更多 >]
```

- 左侧色块：高 22px，宽 4px，颜色 `#214d9c`
- 标题字色：`#333`，字号 22px，字重 600
- 底部边线：`1px solid #e5e5e5`

### 6.2 视频模块

- 容器：左侧 700px，保留 CMS `<video>` 原生控件
- 外层添加细边框 `1px solid #dde6f8` + `border-radius: 4px`
- 悬停时 `box-shadow: 0 8px 32px rgba(33,77,156,0.18)`，过渡 0.3s

### 6.3 数据看板卡片

```
┌─────────────────────────────┐
│   [SVG 图标 48px]             │
│                              │
│   36px  1,2345+              │ ← 金黄色，数字有 countUp 动效
│   13px  培养应用型工程人才数   │ ← 白色半透明
└─────────────────────────────┘
```

- 背景：`rgba(255,255,255,0.08)` 半透明磨砂
- 边框：`1px solid rgba(255,255,255,0.15)`
- 悬停：`background: rgba(255,255,255,0.14)`，`transform: translateY(-4px)`
- 进入视口时：`opacity 0→1` + `translateY(20px→0)`，0.6s ease，每张卡延迟 `0.08s * index`

### 6.4 最新动态列表

- 每行高度 44px，底部 `1px dashed #dde6f8`
- 新闻标题：最大宽度 `calc(100% - 100px)`，超出省略 `text-overflow: ellipsis`
- 悬停：标题色变 `#214d9c`，左侧出现 2px 蓝色进度条（`::before` 伪元素）
- 日期：右对齐，颜色 `#999`

### 6.5 标题区装饰

- 区块顶部左侧色条（`ycit-hp-section-tag`）：`4px × 22px` 蓝色矩形
- 两侧"装饰点"用 CSS `::before/::after` 实现

## 七、动效规范

| 元素 | 动效类型 | 参数 |
|------|---------|------|
| 数据卡片（页面加载） | `fadeInUp` | duration 0.6s, delay 0.08s*n, ease-out |
| 数据数字 | `countUp` JS（IntersectionObserver触发） | 1500ms 线性 |
| 新闻列表项 hover | 左侧 2px 色条滑入 + 文字颜色渐变 | transition 0.25s |
| 视频容器 hover | `box-shadow` 扩散 | transition 0.3s |
| 导航 hover | 背景色渐变（已有，保留原 style.css） | transition 0.3s |
| 模块区块入场 | `fadeIn` + `translateY(30px→0)` | duration 0.7s, scroll trigger |

## 十、文件结构

```
homepage-redesign/
├── DESIGN_SPEC.md          ← 本文档（设计规范）
├── homepage-index.html     ← 首页完整 HTML 模板（含 CMS Freemarker 变量）
└── ycit-homepage.css       ← 首页自定义样式（追加引入到 style.css 之后）
```

### CMS 接入方式

1. 将 `ycit-homepage.css` 上传至 CMS 的 `style/` 目录（或对应静态资源目录）
2. 在 `<head>` 中，在原 `style.css` 引用**之后**追加：
   ```html
   <link rel="stylesheet" type="text/css" href="style/ycit-homepage.css" media="all">
   ```
3. 将 `homepage-index.html` 的 HTML 结构粘贴到 CMS 首页模板对应位置
4. CMS 组件变量（Logo/导航/新闻列表）仍通过 CMS 后台绑定

## 十一、后续页面沿用规范

其他页面（成果概况、改革实践、育人成效等）沿用以下规范：

1. **色彩**：主色 `#214d9c`，强调色 `#f0c040`（仅数字），文字 `#333/666/999`
2. **页面标题栏**：使用 `ycit-hp-section-hd` 样式组件
3. **列表项**：使用 `ycit-hp-news-item` 样式变体
4. **新增 CSS**：继续在 `ycit-homepage.css` 末尾追加，保持 `ycit-[页面缩写]-` 前缀
5. **内页布局**：左侧导航 200px + 右侧内容 1080px（参考原 `.main .wape-left/.wape-right`）
